# Second Post

It's been a long time since I wrote the first blog on this post.  As always, I keep meaning to write stuff, and never quite get around to it.

The previous post sounds slightly naive already.  It was written when the fact that AI could usefully answer questions was quite exciting.  It's all in a very different place now, to the extent that there are large numbers of people arguing very vehemently that it is a bad thing.

I'm in the [Simon Willison](https://simonwillison.net/) camp, that AI is a useful tool, and I like using tools.  It's not a good thing or a bad thing, in the same way that computers are neither a good thing or a bad thing.

However I do agree that we shouldn't pass off AI generated content as human content, so I've added a markup element and visual styling for all AI generated content on this site.  There probably won't be a lot of it, but automatic summaries might be an example. A sample is below:

<div class="ai-generated" data-authorship="ai" aria-label="AI-generated content">
<p class="ai-generated__label">AI-generated content</p>

<p>This is an example of clearly marked AI-generated supporting text. It is useful for things like summaries or boilerplate, but it should never be presented as though a person wrote it unassisted.</p>
</div>
